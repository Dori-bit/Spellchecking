# Умный Spellchecker для русского языка

Вероятностный спеллчекер для поиска и исправления опечаток в русскоязычных текстах.

## Технологии и алгоритмы
* **Алгоритм Питера Норвига**: поиск кандидатов на исправление через генерацию слов с расстоянием Левенштейна 1 и 2.
* **PyMorphy3**: морфологический анализ и проверка существования слова в языке.
* **Сглаживание Лапласа**: вероятностная модель для выбора наиболее подходящего кандидата из списка предложенных.
* **Масштабируемость**: база данных поддерживает более 3 миллионов уникальных словоформ.

## Вероятностная модель
Для выбора лучшего исправления используется формула:
$$P(w) = \frac{count(w) + 0.1}{N + 1}$$
Где $count(w)$ — частота слова в корпусе, а $N$ — общее количество слов в базе.

## Структура проекта
* `src/spellchecker.py` — основной модуль с логикой исправления опечаток.
* `build_big_dict.py` — скрипт для генерации частотного словаря из системной базы.
* `requirements.txt` — список необходимых зависимостей.
* `data/` — директория для хранения сгенерированного словаря (игнорируется Git).

## Инструкция по запуску

1. **Клонируйте репозиторий:**
   ```bash
   git clone <ссылка_на_ваш_репозиторий>
   cd nlp1

2. **Установите зависимости:**
    ```bash
    pip install -r requirements.txt

3. **Сгенерируйте словарь:**
    ```bash
    python3 build_big_dict.py

4. **Запустите программу:**
    ```bash
    python3 src/spellchecker.py
